🔄 Как работает система

1. Создание заявки
Пользователь выбирает тип и заполняет информацию.
2. Проверка
Заявка проходит первоначальную проверку.
3. Рассмотрение
Ответственный раздел рассматривает заявку.
4. Решение
Заявка может быть одобрена, отклонена или отправлена на уточнение информации.
5. Результат
После одобрения создаётся соответствующий профиль, товар, компания или другой объект WORKER PRO.
